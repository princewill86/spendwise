# Security policy

Security fixes apply to the current development branch until versioned releases are available.

Use GitHub's private vulnerability reporting on the repository's Security tab when available. If private reporting is disabled, use a private contact method on the maintainer's profile. Avoid opening a public issue about a vulnerability.

Describe the affected version, impact, and relevant configuration. Include enough detail to assess the issue and omit credentials and real financial data. The maintainer will review the report, request more information if necessary, and coordinate remediation and disclosure with the reporter.
